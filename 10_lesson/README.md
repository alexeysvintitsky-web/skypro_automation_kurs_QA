# 🧪 Домашнее задание №10. PageObject + Allure

## 📌 Описание проекта

Автотест для проверки калькулятора на сайте:  
🔗 https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html

**Что делает тест:**
- Открывает страницу с калькулятором
- Устанавливает задержку 45 секунд
- Нажимает кнопки `7`, `+`, `8`, `=`
- Проверяет, что появился результат `15`

**Технологии:**
- Python
- pytest
- Selenium WebDriver
- Allure (генерация отчетов)
- Page Object паттерн
